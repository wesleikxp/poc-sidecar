Informações de Acesso SFTP

Para se conectar via SFTP (Secure File Transfer Protocol), utilize as seguintes informações:

  • Host: `{{ request.host.split(':')[0] }}` (ou IP público do seu EC2/Load Balancer)
  • Porta: `2222`
  • Usuário: `sftpuser`
  • Senha: `sftppass`
Atenção: Estas credenciais são para fins de demonstração. Em produção, utilize chaves SSH e senhas seguras, gerenciadas por um serviço como AWS Secrets Manager. O usuário terá acesso apenas ao volume compartilhado (`/shared_volume`).
